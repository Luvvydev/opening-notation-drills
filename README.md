# ChessDrills

Learn chess openings by playing the moves, then turn mistakes from your own games into puzzles.

[Explore openings](https://chessdrills.net/openings/library) · [Review a game](https://chessdrills.net/my-games)

## Free to use

* **Opening lessons.** Learn all 25 openings with guided explanations and instant feedback. Try five repeatable lines each in London and Sicilian Practice and Drill.
* **Unlimited game review.** Import from Chess.com or Lichess, or paste a PGN. See where you went wrong and replay your mistakes as puzzles. No account required.

## Premium

Unlock every Practice and Drill line. Save reviews and mistake positions, spot recurring mistakes in Daily Training, and build puzzle packs from multiple games.
